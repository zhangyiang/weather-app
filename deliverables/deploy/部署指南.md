## 第 1 步：把代码推到 GitHub（必须先做这一步）

Render 从 GitHub 拉取代码，所以先把项目上传到 GitHub。

### 1.1 安装 Git（如果没装）
访问 https://git-scm.com/downloads 下载安装，一路下一步即可。

### 1.2 创建 GitHub 仓库
1. 登录 https://github.com （没账号就注册一个，免费）
2. 右上角 **+** → **New repository**
3. 名字填 `weather-app`，选 **Private**（私有，避免泄露），**不要**勾选 "Add a README"
4. 点 **Create repository**

### 1.3 在本地初始化并推送
打开 **PowerShell**，依次执行（把 `你的用户名` 换成你的 GitHub 用户名）：

```powershell
# 进入项目根目录（注意路径里有空格，要带引号）
cd "c:\Users\pro 14\Desktop\555"

# 初始化 git
git init
git branch -M main

# 检查 .gitignore 已就绪（config.json 不会被提交，避免泄露密钥）
git status

# 添加并提交
git add .
git commit -m "聚合天气平台：后端 + 前端 + PWA + Docker 部署配置"

# 关联远程仓库并推送（首次会让你登录 GitHub，按提示在浏览器授权即可）
git remote add origin https://github.com/你的用户名/weather-app.git
git push -u origin main
```

> ⚠️ **安全检查**：推送前确认 `git status` 里**没有** `config.json`（它含真实 API Key，已被 `.gitignore` 排除）。如果看到它，先检查 `.gitignore` 是否生效。

## 第 2 步：在 Render 部署

### 2.1 注册 Render
访问 https://render.com → 右上角 **Get Started** → 用 GitHub 账号登录（一键授权）。

### 2.2 创建服务（两种方式任选其一）

#### 方式 A：用 render.yaml 蓝图（推荐，一键）

1. 登录后进入 Dashboard → 右上角 **New +** → **Blueprint**
2. 选择刚推送的 `weather-app` 仓库
3. Render 会自动识别 `deliverables/render.yaml`
4. **注意**：如果 Render 提示找不到 Dockerfile，在 "Root Directory" 填 `deliverables`，点 Apply
5. 在环境变量页面会看到：
   - `JWT_SECRET` → 已自动生成（不用管）
   - `LLM_API_KEY` → **可选**：填入你的 SiliconFlow API Key（不填则 AI 解读功能降级，不影响其他功能）
6. 点 **Apply** / **Create**

#### 方式 B：手动配置（如果蓝图不工作）

1. Dashboard → **New +** → **Web Service**
2. 选 `weather-app` 仓库，点 **Connect**
3. 填写：
   - **Name**：`aggregate-weather`
   - **Runtime**：`Docker`
   - **Region**：选离你近的（如 Singapore）
   - **Root Directory**：`deliverables`  ← 重要！因为 Dockerfile 在这个子目录
   - **Instance Type**：`Free`
4. **Environment Variables**（手动添加这几项）：
   | Key | Value |
   |-----|-------|
   | `JWT_SECRET` | 点右侧 "Generate" 自动生成一串 |
   | `LLM_API_KEY` | 你的 SiliconFlow Key（可选）|
   | `LLM_BASE_URL` | `https://api.siliconflow.cn/v1` |
   | `LLM_MODEL` | `Qwen/Qwen2.5-7B-Instruct` |
5. 点 **Create Web Service**

### 2.3 等待构建
- Render 会自动 `docker build`，日志实时滚动，约 2~5 分钟完成
- 构建成功后顶部会显示你的域名，形如：
  `https://aggregate-weather-xxxx.onrender.com`
- 点开它，就能看到天气应用了！🎉

### 2.4 验证
- 打开上面的 URL，确认页面正常显示
- 在手机浏览器打开同一 URL，点定位/拍照应该能正常工作（HTTPS 已自带）
- 健康检查：访问 `https://你的域名.onrender.com/api/health` 应返回 JSON

## 常见问题

**Q: 首次访问很慢？**
A: 免费版冷启动需要 30~60 秒，刷新一次即可。之后 15 分钟内的访问都是热的。

**Q: 部署后定位/拍照不能用？**
A: 必须 `https://` 开头才能用，Render 默认就是 HTTPS。如果用 IP 直连 http 不行，请用 onrender.com 域名。

**Q: 想要 MySQL 持久化用户数据？**
A: 免费原型用内存存储即可（重启清空）。若需持久化，可在 Render 加一个免费 PostgreSQL，并修改后端 `config.json` 的 mysql 段（或用环境变量 `MYSQL_HOST` 等）。当前原型不需要。

**Q: 改了代码怎么更新？**
A: 本地 `git add . && git commit -m "xxx" && git push`，Render 检测到推送会自动重新部署（autoDeploy 已开启）。
