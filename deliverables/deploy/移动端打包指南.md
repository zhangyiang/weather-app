# 聚合天气平台 — 移动端打包指南（Android APK + iOS）

> 前置条件：已完成「部署指南.md」，拿到线上地址
> `https://aggregate-weather-xxxx.onrender.com`

我已把应用做成 **PWA**（清单 + 图标 + Service Worker + 全屏适配），所以打包很简单。
下面分三条路线，**按你的设备选**。

---

## 路线一：Android APK（推荐，最简单）— 用 PWABuilder

微软的 PWABuilder 能把你的 PWA 网址直接生成可安装的 Android APK，全程免费、在线操作、无需装 Android Studio。

### 步骤
1. 打开 https://www.pwabuilder.com
2. 顶部输入框粘贴你的线上地址，例如：
   `https://aggregate-weather-xxxx.onrender.com`
   点 **Start**
3. 等几秒，PWABuilder 会扫描你的 PWA。应显示：
   - Manifest: ✅
   - Service Worker: ✅
   - Icons: ✅
   - （如果某项显示 ❌，按页面提示补充，或回来告诉我）
4. 点 **Package For Stores** → 选 **Android**
5. 保持默认选项即可，关键设置：
   - **Package ID**：填 `com.weather.app`（或任意倒序域名，小写）
   - **App Name**：`聚合天气`
   - 其余默认（Signing key 选 "New" 让它帮你生成）
6. 点 **Generate** → 等待生成（约 1~2 分钟）→ 点 **Download** 下载 `.zip`
7. 解压 zip，里面有：
   - `app-release-signed.apk` ← **这就是安卓安装包！**
   - `key.jks`（签名密钥，妥善保管，以后更新要用）

### 安装到手机
1. 把 `app-release-signed.apk` 传到安卓手机（微信/QQ/数据线/U盘均可）
2. 手机上点击该 apk → 允许"安装未知来源应用" → 安装
3. 打开桌面的「聚合天气」图标，即以**全屏 APP 形态**运行（无浏览器地址栏），定位/拍照正常可用

> 💡 如果手机提示"未安装应用"，检查 apk 文件是否完整传输（约 5~10 MB）。

## 路线二：iOS（苹果手机）

> ⚠️ **先说清楚 iOS 的限制**：苹果不允许像安卓那样随意装 APK（iOS 用 .ipa）。
> 真正发布到 App Store 需 **Apple 开发者账号 99 美元/年 + Mac 电脑**。
> 但**自用**有免费办法，下面提供两种，任选。

### 方案 2A：直接"添加到主屏幕"（零成本，最快）
1. 用 iPhone **Safari** 打开线上地址：
   `https://aggregate-weather-xxxx.onrender.com`
2. 点底部 **分享** 图标 → 滚动找到 **"添加到主屏幕"**
3. 桌面会出现「聚合天气」图标，点开就是全屏 APP 体验
4. ✅ 定位、拍照都能用

> 这是最省事的 iOS 方案，效果和原生 APP 几乎一样（已配 `apple-touch-icon` 和全屏 meta）。

### 方案 2B：用 PWABuilder 生成 iOS 包（需 Mac）
1. 在 PWABuilder（同路线一）点 **Package For Stores** → 选 **iOS**
2. 填 **Bundle ID**：`com.weather.app`，App Name：`聚合天气`
3. 需要 Apple ID 账号；PWABuilder 会生成一个 Xcode 工程（.zip）
4. 下载解压后，用 **Mac 上的 Xcode** 打开，连 iPhone，签名（用你的免费 Apple ID 即可"个人开发者"模式）→ 安装
5. 免费个人账号签名 7 天后失效，需重签

> 没有Mac电脑的话，**强烈建议用方案 2A**，体验上无差别。

## 路线三（进阶）：用 Capacitor 本地打包（可选，无需在线服务）

如果你更想"离线打包"或对 PWABuilder 不放心，可用 Capacitor 把网页套壳成 APK。
**需要装：Node.js + Android Studio + JDK**（一次性，较重）。仅当你愿意折腾再看：

<details>
<summary>展开 Capacitor 方案（进阶）</summary>

### 1. 装 Node.js
https://nodejs.org 下载 LTS 版安装。

### 2. 装 Android Studio
https://developer.android.com/studio 安装，打开后用 SDK Manager 装 "Android SDK Platform 34" + "Command-line Tools"。

### 3. 建项目
PowerShell 执行：
```powershell
cd "c:\Users\pro 14\Desktop\555"
mkdir capacitor-app; cd capacitor-app
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android @capacitor/browser
npx cap init "聚合天气" "com.weather.app" --web-dir=../deliverables/html-prototype
```

### 4. 配置（编辑 capacitor.config.json）
把 `server.url` 指向你的线上地址（推荐，走线上后端）：
```json
{
  "appId": "com.weather.app",
  "appName": "聚合天气",
  "webDir": "../deliverables/html-prototype",
  "server": { "url": "https://aggregate-weather-xxxx.onrender.com", "cleartext": false }
}
```
> 这样 APP 直接加载线上页面，后端 API 同源，定位/拍照全可用。

### 5. 生成并打包
```powershell
npx cap add android
npx cap open android
```
Android Studio 打开后：菜单 **Build → Build Bundle(s)/APK(s) → Build APK(s)**，
完成后点 "locate" 找到 `app-debug.apk`，传到手机安装。

</details>

## 常见问题

**Q: PWABuilder 扫描后说 Service Worker ❌？**
A: 确认线上地址是 `https://` 开头，并且 `sw.js` 能访问（浏览器打开 `https://你的域名/sw.js` 应看到代码）。冷启动时第一次访问会注册，再试一次扫描。

**Q: APK 装上后白屏？**
A: 多半是没连上网（免费版 Render 休眠后首次访问慢）。等 1 分钟后重开 APP；或确认手机网络正常。

**Q: 想更新 APP 内容怎么办？**
A: 改代码 → `git push` → Render 自动重新部署 → APP 重新打开就是新版（PWA/WebView 会自动加载最新页面，**无需重新打包 APK**，除非你改了图标/包名）。

**Q: 定位还是不准？**
A: 确认手机系统给了 APP/浏览器定位权限；安卓要在系统设置→应用→聚合天气→权限→位置信息→允许。
